# تطبيق برونز

تطبيق Flutter أصلي (iOS + أندرويد) فوق متجر برونز على سلة: https://bronz-sa.com

- الواجهات كلها أصلية: الرئيسية · الأقسام · البحث · صفحة المنتج · السلة
- البيانات تُقرأ حيًّا من المتجر عبر طبقة ربط مخفية (`lib/core/store_bridge.dart`) — بدون توكن
- الدفع فقط يتم في صفحة سلة الرسمية حتى يُسجَّل الطلب في لوحة التحكم
